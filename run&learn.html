🚀 How to Publish on GitHub Pages:
  1. Save this HTML file as index.html in your GitHub repository.
  2. Upload your 3D character file named character.glb into the exact same folder.
  3. In GitHub, go to Settings → Pages → Build and deployment, select Deploy from a branch (main), and click Save.
  4. The game automatically tries to load ./character.glb on startup and gracefully falls back to the built-in 3D character if not found!
